# OSI 模型與 TCP/IP 模型深度比較指南

在現代網路通訊中，**OSI (Open Systems Interconnection) 模型**與 **TCP/IP 模型**是理解、設計與排除網路故障的兩大核心框架。OSI 模型是一個理論上的標準框架，而 TCP/IP 模型則是當今網際網路實際運作的技術基礎。

---

| OSI 七層模型 | TCP/IP 四層模型 | 各層核心功能說明 | 常見協定 (Protocols) 與設備 |
| :--- | :--- | :--- | :--- |
| **7. 應用層 (Application)** | **4. 應用層 (Application)** | 直接為應用程式提供網路服務，處理使用者介面與網路的互動。 | HTTP, HTTPS, FTP, DNS, SMTP, DHCP |
| **6. 表現層 (Presentation)** | *(合併至應用層)* | 負責資料的格式轉換、加密/解密、壓縮/解壓縮，確保接收方能正確解讀。 | SSL/TLS, JPEG, ASCII, MPEG |

## 2. 核心架構解析

### OSI 模型 (七層)
* **特點**：由國際標準組織 (ISO) 於 1984 年提出，是一個概念性的參考模型。
* **優點**：層級劃分嚴密、職責清晰，非常適合用於教學以及網路概念的標準化。
* **封裝概念**：資料由上而下傳遞時，每一層都會加上該層的標頭 (Header) 或尾記 (Trailer)，這個過程稱為**資料封裝 (Encapsulation)**。

### TCP/IP 模型 (四層/五層)
* **特點**：由美國國防部 (DoD) 資助開發，圍繞網際網路的核心協定（TCP 與 IP）演進而來。
* **優點**：實用性高、架構精簡。在現代網路描述中，有時也會將其「網路存取層」拆開，形成與 OSI 底層對應的 **五層模型**（應用層、傳輸層、網路層、資料連結層、實體層）。

---

## 3. 兩者的關鍵差異

1. **理論與實用性**：
   * **OSI 模型**是先有理論模型才有協定開發，屬於「理論領先」。
   * **TCP/IP 模型**是先有協定（如 TCP/IP 協定組）並在網際網路上廣泛應用後才總結出模型，屬於「實踐領先」。

2. **層級合併**：
   * TCP/IP 認為應用程式本身就能處理資料的格式化（表現層）與會話控制（會議層），因此將 OSI 的上三層簡化為單一的**應用層**。
   * 同樣地，TCP/IP 將底層的實體傳輸與連結控制合併為**網路存取層**。

3. **連線服務模型**：
   * **OSI 模型**的網路層同時支援「物件導向（有連線）」與「非物件導向（無連線）」服務，但傳輸層僅支援有連線服務。
   * **TCP/IP 模型**在網路層（網際網路層）堅持使用無連線的 IP 協定，而在傳輸層則提供可靠的有連線（TCP）與高效的無連線（UDP）兩種選擇。

4. **協定依賴度**：
   * OSI 模型獨立於任何特定的網路協定。
   * TCP/IP 模型則與網際網路標準協定緊密結合。

---

## 4. 常見網路術語與資料單位 (PDU)

在不同的層級中，傳輸的資料有著不同的稱呼（協定資料單位，PDU）：
* **應用層**：資料 (Data)
* **傳輸層**：區段 (Segment，用於 TCP) / 資料報 (Datagram，用於 UDP)
* **網路/網際網路層**：封包 (Packet)
* **資料連結/網路存取層**：訊框 (Frame)
* **實體層**：位元 (Bit)
